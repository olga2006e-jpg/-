# Руководство по интеграции квеста с преподавателями (для фронтенда)

## 🎯 Суть квеста («Сдача сессии трем преподавателям»)
В игре присутствуют 3 ключевых бауманских преподавателя:
1. **Канев Константин Юрьевич** (`kanev`)
2. **Коршунов В.М.** (`korshunov`)
3. **Масленников** (`maslennikov`)

### Механика прохождения:
* Игрок подходит к преподавателю и взаимодействует с ним (например, нажимает `[E]` или кликает).
* Открывается диалоговое окно. **Сверху обязательно выводится характерная фирменная реплика преподавателя** в соответствии с его манерой общения.
* Преподаватель последовательно задаёт **3 учебных вопроса** по своему предмету.
* При ответе на 3 вопроса преподаватель ставит **«Зачёт»** (счётчик зачётов: `0/3` → `1/3` → `2/3` → `3/3`).
* Как только игрок собирает **все 3 зачёта**, на весь экран появляется праздничное окно:
  🎉 **«Поздравляем! Вы прошли игру!»**

## 👨‍🏫 Персонажи и их реплики

### 1. Канев Константин Юрьевич (`id: 'kanev'`)
* **Предмет:** Сети и операционные системы.
* **Характер:** Строгий и требовательный, но абсолютно справедливый. Ценит скорость и конкретику, презирает молчание и невнятные ответы.
* **Обязательные фразы при открытии диалога:**
  * *«Ты умеешь говорить? Ну, говори! Не молчи!»*
  * *«Быстрее! У меня лабораторные сами себя не примут.»*
  * *«Так, тянуть резину не выйдет. Сразу к сути вопроса!»*
  * *«Не мямли, формулируй мысль чётко и по протоколу.»*
* **Вопросы:**
  1. Количество уровней в модели OSI (7 уровней).
  2. Протокол с гарантией доставки пакетов (TCP).
  3. Количество полезных хостов в маске /24 (254).

---

### 2. Коршунов В.М. (`id: 'korshunov'`)
* **Предмет:** Архитектура ПО и распределенные системы.
* **Характер:** Эрудированный, много знает и много рассказывает. Очень любит студентов, хочет знать абсолютно всё по теме до мелочей, постоянно дружески зовёт в бар.
* **Обязательные фразы при открытии диалога:**
  * *«А ты в бар не хочешь?»*
  * *«Когда в бар пойдём?»*
  * *«О, привет! Слушай, а после пар когда в бар пойдём обсуждать микросервисы?»*
  * *«Мне нужно знать абсолютно ВСЁ по этой теме! Давай во всех подробностях!»*
* **Вопросы:**
  1. Значение 'A' (Atomicity / Атомарность) в транзакциях ACID.
  2. Сколько свойств одновременно гарантирует распределенная система по теореме CAP (Только 2).
  3. HTTP-код успешного создания ресурса (201 Created).

---

### 3. Масленников (`id: 'maslennikov'`)
* **Предмет:** Высшая математика и математический анализ.
* **Характер:** Добрый и понимающий в душе, но делает вид, что строгий и вредный. Патологически следит, чтобы никто не списывал и посещал все занятия. Ревнует к другим лекциям.
* **Обязательные фразы при открытии диалога:**
  * *«Почему вас не было на лекции Спиридонова?»*
  * *«ОК.»*
  * *«Если я увижу, что вы пишете лекции Канева на моей лекции, я их сожгу!»*
  * *«Телефон убрали! Списывать вздумали? Я всё вижу!»*
* **Вопросы:**
  1. Первый замечательный предел $\lim_{x \to 0} \frac{\sin x}{x}$ (равен 1).
  2. Производная $e^{2x}$ ($2 \cdot e^{2x}$).
  3. Название матрицы с нулевым определителем (Вырожденная / сингулярная).

## 🚀 Как подключить во фронтенд (2 готовых варианта)

Модуль уже полностью написан и готов в файле:
👉 [`client/src/quest/professorQuest.js`](file:///d:/rip-2026/hackathon/client/src/quest/professorQuest.js)

### Вариант 1. Автоматический (Готовый UI «из коробки»)
Если вы не хотите верстать модалки с нуля, в модуле есть готовый виджет со стилями, HUD статуса зачетов и окном победы:

```javascript
import { ProfessorQuestManager, ProfessorQuestUI } from './quest/professorQuest.js';

// 1. Инициализируем менеджер квеста (прогресс сохраняется в localStorage)
const questManager = new ProfessorQuestManager();

// 2. Инициализируем UI (автоматически создаст плашку зачетов справа сверху и модалки)
const questUI = new ProfessorQuestUI(questManager);

// 3. При приближении к преподу или клике по нему просто вызываем:
// profId может быть: 'kanev' | 'korshunov' | 'maslennikov'
questUI.openDialog('kanev');
```

---

### Вариант 2. Ручной (Использовать только логику, верстка своя)
Если вы делаете свой кастомный интерфейс диалогов:

```javascript
import { ProfessorQuestManager, PROFESSORS } from './quest/professorQuest.js';

const quest = new ProfessorQuestManager({
  onVictory: () => {
    // Вызовется автоматически, когда сданы все 3 зачета!
    alert('Поздравляем! Вы прошли игру!');
  }
});

// Открыть диалог
const dialogData = quest.openDialog('kanev');
console.log(dialogData.greeting); // «Ты умеешь говорить? Ну, говори! Не молчи!»
console.log(dialogData.currentQuestion.text); // Вопрос
console.log(dialogData.currentQuestion.options); // ['4 уровня', '7 уровней', ...]

// Отправить ответ (индекс выбранного варианта 0..3)
const result = quest.submitAnswer('kanev', 1);
console.log(result.isCorrect); // true / false
console.log(result.feedbackPhrase); // Коронная реакция препода на ответ
console.log(result.creditEarnedNow); // true, если это был 3-й вопрос и получен зачёт!
console.log(result.isAllCreditsEarned); // true, если собраны все 3 зачета

// Проверить текущую сводку зачетов
const summary = quest.getSummary();
// { earnedCount: 1, totalRequired: 3, isCompleted: false, credits: { kanev: true, ... } }
```
