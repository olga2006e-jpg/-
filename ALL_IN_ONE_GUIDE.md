## 1. Концепция и идея проекта

* **Название**: «Ночь в Бауманке» (Haunted Academy).
* **Жанр**: Мультиплеерный 3D-квест в веб-браузере с автономными ИИ-агентами.
* **Сеттинг**: Ночной мистический корпус МГТУ им. Н.Э. Баумана.
* **Главная задача**: Снять психологический барьер и страх первокурсников перед первой сессией через интерактивную «репетицию» сдачи зачётов призракам реальных преподавателей.
* **Роль агентов**: Не обычные чат-боты, а полноценные акторы вселенной:
  * Имеют постоянную память о действиях студента (SQLite).
  * Обладают уникальным характером и реальными цитатами преподавателей.
  * **Физически меняют мир** вокруг игрока (материализуют свет, серверные стойки, открывают порталы).

## 4. Техническая архитектура и бэкенд

* **Сетевой протокол**: WebSocket (порт `3001`, endpoint `/ws`).
* **Тактовая частота**: 20 тиков в секунду (50 мс такт синхронизации).
* **База данных**: SQLite с включенным журналом **WAL (Write-Ahead Logging)** — нулевые блокировки при параллельном чтении и записи.
* **Кэширование**: 10% «горячих» чанков и сессий игроков удерживаются в RAM для субмиллисекундного отклика.
* **Авторизация**: Токены сессий, поддержка гостевого режима без пароля, предотвращение дублирования никнеймов (superseded socket disconnect 4001).
* **Отказоустойчивость**: AI Fallback (эвристический движок правил), если внешняя модель Ollama временно недоступна.

## 5. 3D-объекты, составные анимации и физика

Модули: `client/src/animatedProps.js` и `client/src/physics.js`.

1. **Напольные часы (Grandfather Clock)**:
   * Маятник качается по закону гармонических колебаний $\theta(t) = \theta_0 \cos(\omega t)$.
   * Две шестерни вращаются с кинематическим передаточным числом 1:4.
2. **Обсерваторный телескоп**:
   * Азимутальная поворотная платформа (вращение 360°).
   * Оптическая труба с вертикальным подъемом (элевация).
   * Пульсирующая линза с эффектом фокусировки.
3. **Арканный гироскоп**:
   * 3 независимых взаимно перпендикулярных кардановых кольца.
   * Левитирующий кристалл в центре с радиальным свечением.
4. **Серверная стойка**:
   * 2 работающих кулера охлаждения.
   * 24 анимированных светодиода активности сетевых портов.
5. **Физический движок**:
   * Клавиша **[F]** — бросок сферы по вектору взгляда игрока ($v_0 = 12$ м/с).
   * Гравитация $g = -9.81$ м/с², упругие отскоки ($e = 0.55$).
   * Процедурный синтез звука удара через Web Audio API.

## 7. ИИ-агенты и динамическое изменение мира

Модули: `server/ai/agentService.js`, `server/ai/personalities.js`.

* **Классификатор намерений игрока** (`classifyIntentActions`):
  * Слова «темно», «заблудился», «помоги» $\rightarrow$ мутация **`SPAWN_LIGHT_BEAM`** (вертикальный световой столб-маяк).
  * Слова «сервер», «вычислить», «кластер» $\rightarrow$ мутация **`SPAWN_SERVER_RACK`** (спавн серверной стойки).
  * Слова «портал», «телепорт», «врата» $\rightarrow$ мутация **`SPAWN_PORTAL`** (открытие мерцающего портала).
* Все мутации мира мгновенно рассылаются сервером по WebSocket сообщением `WORLD_MUTATION` всем игрокам в комнате.

## 8. Квест 3 преподавателей («Сдача сессии»)

Модуль: `client/src/quest/professorQuest.js`.

### Персонажи и коронные реплики:
1. **Канев Константин Юрьевич (`kanev`)** — Сети и ОС:
   * *«Ты умеешь говорить? Ну, говори! Не молчи!»*
   * *«Быстрее! У меня лабораторные сами себя не примут.»*
   * *«Так, тянуть время не выйдет. Сразу к сути вопроса!»*
2. **Коршунов В.М. (`korshunov`)** — Архитектура ПО:
   * *«А ты в бар не хочешь?»*
   * *«Когда в бар пойдём?»*
   * *«Мне нужно знать абсолютно ВСЁ по этой теме, давай в деталях!»*
3. **Масленников (`maslennikov`)** — Высшая математика:
   * *«Почему вас не было на лекции Спиридонова?»*
   * *«ОК.»*
   * *«Если я увижу, что вы пишете лекции Канева на моей лекции, я их сожгу!»*
   * *«Телефон убрали! Списывать вздумали? Я всё вижу!»*

### Игровой процесс:
* Каждый преподаватель задает **3 вопроса** по своему предмету.
* После 3 ответов студент получает **«Зачёт»** (статус `1/3` $\rightarrow$ `2/3` $\rightarrow$ `3/3`).
* Когда собраны все 3 зачета, на весь экран появляется окно:  
  🎉 **«Поздравляем! Вы прошли игру! Все 3 зачёта получены!»**

## 9. Админ-панель (Телеметрия FPS/Ping и мир)

* **Адрес**: `http://localhost:3001/admin`
* **Сбор метрик**:
  * Клиенты отправляют телеметрию по WebSocket: `fps`, `ping` (RTT замеряется пинг-понгом), `loadedChunks`.
  * Админка выводит статус каждого подключенного игрока в реальном времени.
* **Управление миром**:
  * Ползунки гравитации (от -1.0 до -25.0 м/с²), плотности тумана, освещения.
  * 1-клик пресеты: **«Лунная гравитация»**, **«Хэллоуин»**, **«Ясный день»**.
  * Переключение поведения агентов: `strict` (строгий), `helpful` (помогающий), `talkative` (болтливый).
  * Кнопки принудительного спавна мутаций мира и глобального оповещения в чат.

## 10. Инструкция для фронтенд-разработчика

Все готовые модули лежат в проекте и готовы к импорту:

### А. Подключение квеста сессии и окна победы:
```javascript
import { ProfessorQuestManager, ProfessorQuestUI } from './quest/professorQuest.js';

// Инициализация менеджера и встроенного UI (HUD зачетов в углу + модалка)
const questManager = new ProfessorQuestManager();
const questUI = new ProfessorQuestUI(questManager);

// При клике или приближении к преподавателю:
questUI.openDialog('kanev');        // или 'korshunov', 'maslennikov'
```

### Б. Подключение 3D-моделей преподавателей:
* **Спектральный парящий призрак** (мистический стиль):
```javascript
import { SpectralProfessorNPC } from './characters/spectralNPC.js';
const ghostKanev = new SpectralProfessorNPC('kanev', scene);
ghostKanev.setPosition(0, 0, 8);
// в цикле анимации:
ghostKanev.update(delta, camera.position);
```
* **Человеческая модель в поло**: `client/src/characters/konstantinNPC.js`.

### В. Отправка телеметрии FPS и Ping в админку:
```javascript
network.sendTelemetry({
  fps: Math.round(fps),
  ping: currentPingMs,
  loadedChunks: chunkManager.getLoadedCount()
});
```
