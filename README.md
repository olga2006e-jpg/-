# 🎃 Хакатон: Haunted Academy — 3D Multiplayer Educational Metaverse

> Многопользовательская 3D-игра на **Three.js** и **WebSockets** с процедурным стримингом чанков (кэш $\le 10\%$) и локальным адаптивным ИИ без подключения к интернету.

---

## ⚡ Быстрый старт (за 1 минуту)

### На ноутбуке-сервере:
```bash
# 1. Установить зависимости
npm install

# 2. Собрать клиент
npm run build

# 3. Запустить сервер
npm start
```
Сервер выведет в консоль:
```text
🎃 HAUNTED ACADEMY — HACKATHON SERVER READY!
📡 Localhost:     http://localhost:3001
🌐 LAN (Wi-Fi):   http://192.168.x.x:3001
```

### На ноутбуках-клиентах:
1. Подключитесь к тому же Wi-Fi (или мобильной точке доступа), что и сервер.
2. Откройте в браузере (Chrome / Safari / Edge) адрес: `http://192.168.x.x:3001`.
3. Введите имя, выберите цвет ауры и нажмите **Enter**.

## 🏗 Архитектура решения

1. **3D Рендеринг (Three.js):** 
   * Сцена с ночным туманом, тенями, процедурными объектами (тыквы с мерцанием, факелы, колонны, надгробия).
   * Управление камерой от первого лица (WASD + мышь).
2. **Стриминг со строгим кэшем $\le 10\%$:**
   * Мир состоит из 100 чанков ($10 \times 10$).
   * На клиенте реализован менеджер LRU: в памяти удерживается максимум 10 секторов.
   * При перемещении дальние чанки выгружаются с очисткой геометрий и материалов (`dispose`).
   * В правом верхнем углу экрана отображается постоянный монитор соблюдения кэша для жюри.
3. **Локальный ИИ (Ollama):**
   * Модель `qwen2.5:3b` или `llama3.2:1b` работает на локальном хосте сервера.
   * Адаптивная память FSM: персонажи запоминают изученные игроком факты и не повторяются при последующих беседах.
   * Встроенный оффлайн-эмулятор для мгновенной подстраховки.
4. **Персистентность:**
   * Позиции игроков, инвентарь и состояние диалогов сохраняются на сервере в `data/gameState.json`.

## 🏆 Сценарий победной защиты перед жюри

1. **Этап 1: LAN Мультиплеер**
   * Показываете 2-3 ноутбука рядом: персонажи бегают по замку, переписываются в чате.
   * Показываете судьям плашку в правом верхнем углу: `Кэш: 7/10 (7.0%) [СОБЛЮДЕНО ✅]`.
2. **Этап 2: Диалог с адаптивным ИИ**
   * Подходите к Эйнштейну, жмете клавишу `E`. Задаете вопрос про время.
   * Задаете повторный вопрос — Эйнштейн адаптируется и меняет тему.
3. **Этап 3: Полная автономность**
   * Демонстративно выключаете Wi-Fi на ноутбуке-сервере.
   * Запускаете `http://localhost:3001` — всё работает без интернета.
