# 🌐 ТЗ для Девушки 3: Backend, Multiplayer & Quests Lead

> **Твоя миссия:** Управлять центральным сервером игры. Обеспечить надежный сетевой обмен между ноутбуками в LAN/Wi-Fi, сохранение данных в базу данных и механику командного квеста.

---

## 📁 Твои рабочие файлы:
* `server/index.js` — точка входа сервера, запуск на порту 3001, определение локального IP
* `server/multiplayer.js` — WebSocket логика, авторизация, цикл тиков 20 Hz, обработка сообщений
* `server/world.js` — генератор 100 чанков мира, спавн предметов и призраков
* `server/auth.js` — выпуск токенов
* `server/db.js` — сохранение прогресса игроков в файл `data/gameState.json`

---

## 🎯 Чек-лист задач:

### 1. Подключение всех ноутбуков по Wi-Fi (LAN)
- [ ] Запусти сервер:
  ```bash
  npm start
  ```
- [ ] В логе консоли найди строчку вида:
  ```text
  🌐 LAN (Wi-Fi):   http://192.168.1.45:3001
  ```
- [ ] Сообщи этот IP всем подругам по команде. Они открывают этот адрес в Chrome.
- [ ] Проверь, что 4 ноутбука одновременно двигаются на карте и видят друг друга без фризов.

---

### 2. Квестовая логика: «Тайна Хэллоуинских Врат»
- [ ] Добавить в `server/multiplayer.js` обработку сообщения с вводом пароля:
```javascript
// Внутри multiplayer.js (on message):
if (msg.type === 'SUBMIT_GATE_CODE') {
  const code = (msg.code || '').trim();
  const WIN_CODE = '2327'; // 2 (E=mc^2) + 3 (Пирамиды) + 2 (Группа радия) + 7 (Склеп)
  
  if (code === WIN_CODE) {
    broadcast({
      type: 'VICTORY',
      winner: authenticatedUser,
      message: `🎉 Игрок ${authenticatedUser} и команда разгадали тайны призраков и открыли Врата!`
    });
  } else {
    ws.send(JSON.stringify({
      type: 'CODE_INCORRECT',
      message: 'Замок звякнул цепями: код неверен! Спросите призраков о подсказках.'
    }));
  }
}
```

---

### 3. Предметы и артефакты в чанках
- [ ] В `server/world.js` добавить коллекционные предметы (свитки, колбы, песочные часы), разбросанные по чанкам.
- [ ] Когда игрок наступает на координаты предмета — сервер добавляет его в `inventory` игрока в `db.js`.

---

### 4. Подготовка демонстрации для судей (2 сценария)
- [ ] **Сценарий 1 (Сеть):** Сервер раздает данные по Wi-Fi на другие ноутбуки.
- [ ] **Сценарий 2 (Оффлайн):** Выключаешь Wi-Fi на своем ноутбуке. Открываешь `http://localhost:3001`. Всё должно работать без единого запроса во внешний интернет!

---

## 🔍 Критерии приёмки:
1. Сервер стабильно держит 4 подключения одновременно с задержкой < 50мс.
2. При перезапуске сервера позиции игроков восстанавливаются из `data/gameState.json`.
3. Игра полностью играбельна при отключенном кабеле и выключенном Wi-Fi.
