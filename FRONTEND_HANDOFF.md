# Фронтенд: учебный павильон

База: `origin/feature/Sasha`, коммит `eb57590`. Работа: `feature/compact-campus-ui`.

## Запуск

На серверном ноутбуке из папки проекта: `npm run build`, затем `npm start`.
Открыть `http://localhost:3001`. Остальным ноутбукам — LAN-адрес этого сервера, порт 3001.
Для разработки: параллельно `npm start` и `npm run dev`; Vite проксирует HTTP и `/ws`.
Модель Ollama должна быть загружена заранее; ИИ и приложение размещаются на одном ноутбуке.

## Что изменилось

Один уровень на y=0, высота глаз 1.6. Холл (0,0), цифровая лаборатория (-1,0),
математическая гостиная (0,-1), лаборатория света (1,0). Шаг координат — 24.
Лестницы, лифт и переключение этажей убраны из маршрута. Карта показывает фактические комнаты.
Серверный world.js изменён для согласования геометрии, NPC и предметов с фронтендом;
при слиянии серверных веток сохранить эту раскладку. Существующий протокол сообщений сохранён.

Новый вход, HUD, карта, инвентарь с подсказками, форма сейфа, диалоги и экран победы.
Состояния ошибки сети и повторного входа. Вход закрывается только после AUTH_SUCCESS.
История открытых диалогов сохраняется на клиенте в пределах сессии; постоянная память — существующий сервер.
Ответ LLM и ответ локального алгоритма подписаны отдельно по usedLLM.
Пользовательский текст выводится через textContent. Шрифты системные, внешних ресурсов нет.
Управление останавливается при вводе текста и открытии окна. Закрытие окна снимает фокус.
Исправлены NaN в яркости анимированного сейфа, двойное переключение фонаря и пропущенный импорт audio.
Коллизии стен учитывают их центр по высоте. Устаревшие ответы чанков не добавляются в сцену.

## Управление и маршрут

WASD — движение; мышь после клика по сцене — обзор; E — диалог или сейф;
M — карта; J — находки; Enter — чат; L — фонарь; Esc — закрыть окно / освободить курсор.
Из входа прямо — математика, налево — технологии, направо — свет.
Эйнштейн и Геродот — в холле; остальные три преподавателя — в своих лабораториях.
Четыре светящихся предмета содержат подсказки к коду 2327. Сейф — в холле справа, (7,7).

## Проверено

- Production-сборка Vite успешна.
- `node --test test/compact-layout.test.js`: структура 100 секторов, один уровень,
  все пять NPC и четыре уникальных предмета находятся внутри доступных помещений.
- Headless Edge, два браузерных клиента: взаимное появление, чат, безопасный вывод HTML как текста.
- Фактический проход WASD из холла через дверь до преподавателя математики; y=1.6.
- Ответ NPC в режиме локального алгоритма; ввод в диалоге не двигает игрока.
- Карта после закрытия диалога, инвентарь, отказ неверного кода и экран победы.
- Скриншоты при 1366×768 и 1920×1080; ошибок JS и внешних запросов при проверке нет.

## Ограничения

Демонстрационный интерьер состоит из четырёх помещений. Существующая сетка мира 10×10
сохранена, остальные сектора — внешний двор. Кэш ограничен десятью секторами и обычно
загружает окно 3×3. HUD явно сообщает, что это доля количества секторов, а не байтов.
Это не доказательство ограничения 10% по объёму данных.
Настоящая модель Ollama и физическая LAN между ноутбуками в этой проверке не проверялись.
Хранилище JSON и гостевая авторизация оставлены существующими. Текущий auth.js при входе
сбрасывает позицию ко входу; фронтенд не меняет эту серверную политику.
Vite предупреждает о размере общего JS-бандла (около 637 КБ до gzip, включает Three.js).

## Интеграция файлов ИИ команды

Файлы memory.js, personalities.js и agentService.js из Telegram адаптированы к текущему
API AgentService.chat, без замены формата WebSocket-сообщений. Личности и учебные загадки
добавлены к существующим базам знаний. Память хранится существующим JSON-хранилищем,
ошибочные ответы больше не засчитываются. Последовательность: STORY → RIDDLE → DONE.
Учебные загадки NPC не заменяют четыре предметные подсказки к сейфу (2327).
Режим LLM использует Ollama /api/chat, таймаут 5 секунд с отменой запроса.
При недоступности Ollama работает локальный последовательный учебный алгоритм.

Настройки в PowerShell перед npm start:

```powershell
$env:OLLAMA_HOST = "http://127.0.0.1:11434"
$env:OLLAMA_MODEL = "qwen2.5:0.5b"
npm start
```

OLLAMA_URL поддерживается как альтернативное имя для адреса, OLLAMA_HOST имеет приоритет.
Жёстко заданный LAN-IP из присланного файла не используется. Модель нужно предварительно
загрузить: ollama pull qwen2.5:0.5b. GAME_DATA_DIR позволяет задать отдельную папку хранения
для тестов. Пользовательское хранилище при тестировании не затрагивается.

Дополнительно пройдены `node --test test/compact-layout.test.js test/ai-lessons.test.js`:
4 теста. Проверены изоляция памяти игроков/NPC, восстановление после чтения файла,
точный счётчик ходов, отказ неверной загадке, правильный ответ и протокол ответа модели
через подставной fetch. Это проверка интеграции, не запуск настоящей модели.
